# 🚀 DevConnect

A full-stack social media platform built with **FastAPI + React** featuring authentication, posts, likes, comments, follow system, notifications, saved posts, trending feed, user search, image uploads, and a modern responsive UI.

---

## ✨ Features

### Authentication
- JWT Authentication
- User Registration & Login
- Secure Password Hashing

### User
- User Profile
- Edit Profile
- Follow / Unfollow
- Followers & Following
- User Search

### Posts
- Create Post
- Delete Post
- Image Upload (Cloudinary)
- Feed
- Trending Posts
- Saved Posts

### Social Features
- Like / Unlike
- Comments
- Save Posts
- Notifications
- Follow Notifications
- Like Notifications
- Comment Notifications

### Backend
- FastAPI
- SQLAlchemy ORM
- PostgreSQL
- JWT
- Repository Pattern
- REST APIs

### Frontend (In Progress)
- React 19
- Vite
- Tailwind CSS
- React Router
- Axios
- TanStack Query
- Framer Motion

# 🚀 Getting Started

## Backend

```bash
pip install -r requirements.txt
```

```
uvicorn app.main:app --reload
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```
